## 🤖 Inteligência Artificial

- 🧠 **LLMs & RAG** — assistentes que respondem com base em documentos e dados próprios (embeddings, busca vetorial, recuperação de contexto)
- 🔌 **MCP (Model Context Protocol)** — integração de modelos com ferramentas, APIs e sistemas
- 🎯 **Fine-tuning** — ajuste de modelos para domínios e tarefas específicas
- 🕹️ **Agentes de IA** — agentes que planejam e executam tarefas com ferramentas
- ⚙️ **Esteira de desenvolvimento agêntica** — PRD → tech spec → tarefas → código → PR com agentes, rodando em GitHub Actions
- 📝 **NLP aplicado à engenharia de software** — classificação de dívida técnica auto-admitida (SATD) com TF-IDF, Sentence-BERT e LSTM
